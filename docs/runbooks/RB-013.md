# RB-013. Tarmoq xatolari (AL-029)

1. `ip -s link show <iface>`; `ethtool -S <iface> | grep -i -E "err|drop"`.
2. `mtr -rwc 50 <tashqi_manzil>`; MTU: `ip link | grep mtu`.
3. Provayder tarmoq muammosi bo'lishi mumkin — status sahifa/murojaat.
