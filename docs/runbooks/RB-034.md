# RB-034. Restore drill (AL-081..AL-083)

10.8-bo'limdagi qadamlar. Qisqa: vaqtinchalik `postgres:<major>` konteyner → bazani yaratish →
`gunzip -c <fayl> | psql ... -v ON_ERROR_STOP=1` → jadval/qator sonini solishtirish → natijani panelga kiritish.
**Ishlab turgan bazaga tegmang.**

Panelda: Zaxiralar → loyiha kartasi → "Restore drill" → "Drill natijasini kiritish" (sana, fayl, davomiylik, jadval/qator soni, natija).

- **AL-081** (info): oxirgi muvaffaqiyatli drill davriylikka (`drill_every_days`, standart 90 kun) 14 kundan kam qoldi.
- **AL-082** (warning): davriylik o'tdi yoki drill hech qachon o'tkazilmagan. Muvaffaqiyatsiz drill taymerni qayta boshlamaydi.
- **AL-083** (high): oxirgi drill `failed`. Yangi (muvaffaqiyatli) drill kiritilgach o'zi yopiladi.
- Davriylikni o'zgartirish: loyiha zaxira siyosatida `drill_every_days`.
