# RB-044. Nazoratchi'ni yangi serverda tiklash

Maqsad: RTO ≤ 60 daqiqa (NFR-REL-006). Umumiy tartib: TZ 15.9.

**Kerak bo'ladi (parol menejeridan):** `NAZORATCHI_MASTER_KEY`, `age` **maxfiy** kalit fayli, `.env` nusxasi (yoki uning
qiymatlari). Zaxira fayli — Owner'ning Telegram chatidagi eng yangi `nazoratchi-selfbackup-*.json.gz.age`
(45 MB dan katta bo'lsa `.partNNofMM` bo'laklari, hammasi).

> Diqqat: kanal sirlari (`config_enc`) zaxirada `NAZORATCHI_MASTER_KEY` bilan shifrlangan holda. Master kalit yo'qolsa
> kanal tokenlari ochilmaydi — kanallarni panelda qayta kiritish kerak bo'ladi.

## Qadamlar

1. Yangi server tayyorlang (TZ 15.2), `nazoratchi` papkasini yarating, `.env` ni tiklang (`NAZORATCHI_MASTER_KEY` aynan
   eskisi bo'lsin), `deploy/docker-compose.yml` ni qo'ying.
2. Bo'sh bazani ko'taring va sxemani yarating:
   ```bash
   docker compose pull && docker compose up -d db redis
   docker compose run --rm web python manage.py migrate --noinput
   ```
3. Zaxira faylini va maxfiy kalitni konteynerga bering va tiklang (bo'laklar bo'lsa tartib bilan sanab o'ting):
   ```bash
   docker compose run --rm -v "$PWD/restore:/restore:ro" web \
     python manage.py restore_self_backup /restore/nazoratchi-selfbackup-YYYYMMDD-HHMM.json.gz.age \
     --identity /restore/age-secret.key --yes
   ```
   Buyruq shifrni ochadi, `loaddata` bilan reyestr, incident, audit, kanal va qoidalarni yuklaydi (metrikalar zaxirada yo'q).
4. Hammasini ko'taring: `docker compose up -d`. `restore/` papkasi va maxfiy kalitni serverdan **o'chiring**.
5. DNS: `nazoratchi.<domen>` ni yangi IP ga yo'naltiring (TTL 300 s). Agentlar domen o'zgarmagani uchun o'zi ulanadi,
   navbatdagi ma'lumot yuboriladi.
6. Watchdog'ning `WATCHDOG_URL` i o'zgarmaydi (S-01 da); `NAZORATCHI_BACKUP_AGE_PUBKEY` ni `.env` ga qaytaring.

## Tekshirish

- `curl -fsS http://127.0.0.1:8040/readyz` → `200`.
- Panelga kirish mumkin, reyestr to'liq, serverlar bir necha daqiqada "Onlayn" bo'ladi.
- Telegram kanalida sinov xabari kelishi; `manage.py self_backup` yangi zaxirani yuboradi.
- Natija va sarflangan vaqtni drill jurnaliga yozing.
